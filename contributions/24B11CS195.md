## Three Git Commands and Their Purpose

1. `git status` — Shows the current branch and the status of files.
2. `git add .` — Stages modified and new files for the next commit.
3. `git commit -m "message"` — Saves staged changes in the local repository with a descriptive message.

## Purpose of GitHub

GitHub is an online platform for hosting Git repositories, sharing source code, collaborating with others, and reviewing project changes.

## Benefit of Branches

Branches allow developers to work on new features or documentation separately without directly changing the main branch. Changes can be reviewed and merged when ready.
